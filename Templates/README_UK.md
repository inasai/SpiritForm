# Шаблони Spirit Form

Папка `Templates` лежить у корені проєкту поруч із `src` і `docs`. Гра її не бачить і не збирає, це лише заготовки. Беріть потрібну папку, копіюйте файли у вказані місця й замінюйте назви-заглушки на свої.

| Папка | Для чого | Докладна інструкція |
|---|---|---|
| `Mob` | Істота (моб): код, модель, відображення, текстура, яйце, поява у виміру | `docs/CREATURES_UK.md` |
| `Dimension` | Вимір: правила, ландшафт, біом, об'єкти (руди, дерева), код входу | `docs/DIMENSION_UK.md` |
| `Items` | Зброя, інструменти й обладунки: код, матеріали, моделі, рецепти, зачарування | `docs/TOOLS_ARMOR_UK.md` |

## Назви-заглушки

У шаблонах є три види написання однієї назви. Замініть їх усі на свою:

- `MyCreature` (великі літери, без пробілів): назва класу;
- `my_creature` (малі літери, підкреслення): назва в грі й файлів (id), лише `a-z`, `0-9`, `_`;
- `MY_CREATURE`: назва константи в коді.

Так само в інших папках: `MyDimension` / `my_dimension` / `my_biome`, `MyWeapon` / `my_weapon`, `MyArmor` / `my_armor`, `MyTier` / `MY_TIER`.

## Як замінити назви в IntelliJ (macOS)

1. Скопіюйте файли шаблону у проєкт (шляхи вказані в кожній папці у файлі `README_UK.md`).
2. Назву класу змінюйте через **Shift+F6** (Rename), так оновляться й посилання в коді.
3. Текстові заглушки (`my_creature`, `MY_CREATURE`) замініть в усьому проєкті: **Cmd+Shift+R** (Replace in Files), у полі Scope оберіть Project Files.
4. Назви файлів JSON і png перейменовуйте вручну (клавіша Enter на файлі в Project).

Усі файли в шаблонах «чисті»: без текстур-заповнювачів і чужих назв. Текстури це порожні прозорі png потрібного розміру, їх треба намалювати.
